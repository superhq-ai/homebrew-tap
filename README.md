# homebrew-tap

Homebrew formulae and casks for SuperHQ projects.

## Install

```bash
brew tap superhq-ai/tap
```

## Formulae

| Formula | Description |
|---------|-------------|
| `shuru` | Local-first microVM sandbox for AI agents |

```bash
brew install shuru
```

## Casks

| Cask | Description |
|------|-------------|
| `superhq` | AI agent orchestration desktop app |

```bash
brew install --cask superhq
```
